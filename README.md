# RustSGL

This project is currently in work. It is a port of the original SGL library available over here: https://github.com/mrjacksonsapien/SGL
 
The first goal of this project was to significantly improve performance compared to the first prototype by working with a compiled language and using SIMD instructions to parallelize rendering (not as great as a GPU but it's way better). The second goal here is to hopefully be able to add more shading features like lighting, textures and color blending.
